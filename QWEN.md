# Инструкция — в AGENTS.md

Перед любой правкой прочитайте **[AGENTS.md](AGENTS.md)** целиком: где лежит
код (весь сайт — один файл `index.html`), как опубликовать и чего делать
нельзя. Карта кода — в [README.md](README.md).

Коротко: `git pull` → правка `index.html` → `node scripts/check-site.mjs` →
коммит → `git push origin main`. Через минуту изменения на сайте.
